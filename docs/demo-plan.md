# Demo plan & milestones

## MVP (must have)
- [ ] Arm calibrated + teleop working
- [ ] Bottle fixture printed and mounted
- [ ] Cap-gripper pads printed
- [ ] Scripted open sequence removes a twist cap from a bottle in the fixture
- [ ] Works on a child-proof (push-and-turn) cap

## Nice to have
- [ ] Vision-based bottle pick from a random position on the table
- [ ] Works across 3+ bottle sizes (configs/bottles.yaml)
- [ ] Learned ACT policy for pick & place
- [ ] Force sensing in the gripper pads
- [ ] Voice trigger ("open my pills")

## Pitch (2 min)
1. Problem: millions struggle with child-proof caps (arthritis, Parkinson's, stroke).
2. Live demo: place bottle → robot opens it.
3. How it works: low-cost open-source arm + custom attachment + LeRobot.
4. Next steps: more cap types, dispensing, smaller/cheaper form factor.
